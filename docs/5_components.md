## Компоненты

* _shef.insync:import.from.file_ - для ручной загрузки файла
* _shef.insync:import.stat.local_ - для анализа процесса импорта, поддерживает запуск/остановку агентов

> Модуль, в своих компонентах, добавляет правила клика по ссылкам на страницы, с целью открытия их в слайдере.
