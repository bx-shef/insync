# Страницы

> Пример смотреть в модуле **[shef.demosync](https://marketplace.1c-bitrix.ru/solutions/shef.demosync/)**

* `/page/shinsync/statimportlocal/` - [страница статистики испорта](/page/shinsync/statimportlocal/)
* страницы, ссылки для импорта из файла создаются модулями самостоятельно через `Bitrix\Intranet\CustomSection\Entity\CustomSectionTable`.

> Модуль, в своих компонентах, добавляет правила клика по ссылкам на страницы, с целью открытия их в слайдере.
